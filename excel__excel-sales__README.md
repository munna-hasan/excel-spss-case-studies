# Sales Performance Dashboard

An Excel sales dashboard analyzing 50 orders through sales, cost, gross profit and margin KPIs, with product and regional comparisons and documented regional slicer selections.

**Tools** — Microsoft Excel, Pivot Charts, Slicers, KPI reporting, Data relationships

[Read the original case study (PDF)](sales-dashboard-case-study.pdf)

## Reported findings

- The 24-inch monitor generated 132,510 in sales, or 26.6% of total revenue, according to the report.
- Dhaka accounts for 143,730, or 28.9% of the displayed regional sales total. Region attribution should be reconciled against the separate Store ID lookup as noted in the supplied report.
- Regional slicers update the workbook KPI cards and product/region charts. Documented filter states are alternative views of the same dataset.

## Scope

The precise gross margin is 23.53%; the original dashboard rounds it to 24%. Gross profit subtracts product costs; operating overhead, returns, discounts and taxes were not modeled separately. The report flags a discrepancy between dashboard region attribution and a separate Store ID lookup. No original Excel workbook was supplied for this website.
